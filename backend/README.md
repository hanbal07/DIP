# Document Intelligence Platform

A production-style, end-to-end AI document processing platform. Upload PDFs, scanned PDFs,
images and supported documents; validate, process, classify, OCR, extract structured
information, generate embeddings, store in PostgreSQL + pgvector, and answer questions
over your documents with RAG and source citations.
